# Module-6-Assignment
First, install the latest version of Python in Windows. To do so, open the Windows Command Prompt, and type the following command: winget install Python.Python.3.14.

Next, install the required dependencies by typing the following command in the Command Prompt: pip install opencv-python numpy matplotlib.

Then, open the "Module 6 Assignment" zipped folder, then copy all the files in the "Module 6 Assignment copy into Documents zipped folder" inside the same "Module 6 Assignment" zipped folder into your Documents directory in your computer.

Then, type "cd Documents" in the Command Prompt.

Finally, type "python (file_name)" in the command prompt to run the python scripts (Ex: to run the generate_flow.py file, type "python generate_flow.py" in the command prompt).
